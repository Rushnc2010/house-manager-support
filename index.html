Nous contacter

Pour signaler un problème ou poser une question, ouvrez un ticket sur la page des demandes d'assistance.

Pendant la phase de test, vous pouvez aussi envoyer un commentaire directement depuis l'app TestFlight (capture d'écran puis « Partager la bêta »).

Ne joignez jamais de données personnelles (montants, documents, informations de santé) à une demande.

Questions fréquentes

Faut-il un compte ?
Non. L'app ne demande aucun compte et ne se connecte à aucun serveur.

Où sont mes données ?
Uniquement sur votre appareil, dans une base chiffrée. Personne d'autre, y compris l'éditeur, n'y a accès.

Comment changer d'appareil ?
Réglages → Sauvegarde : exportez une sauvegarde chiffrée, enregistrez-la où vous voulez (Fichiers, AirDrop…), puis importez-la sur le nouvel appareil.

J'ai oublié mon code.
Les données étant chiffrées sur l'appareil, elles ne peuvent pas être récupérées sans le code ou Face ID. Gardez une sauvegarde à jour.

Je ne reçois pas les rappels.
Vérifiez que les notifications sont autorisées dans Réglages iOS → Notifications → Super House Manager.
